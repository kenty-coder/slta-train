1. この段階の目安となるSLTAプロフィール

自分から話すことがほとんどなく、質問にも返事が出にくい段階です。一方で、聞いた言葉をまねして言う力（復唱）は比較的保たれ、数字や曜日のような決まった並びの言葉（系列語）も、言い始めを手伝うと続けて言えることが多いのが特徴です。理解は単語なら比較的保たれますが、長い指示では低下します。

2. 同じタイプの他の重症度との違い

重症度話す力の目安教材の中心
重度（この教材）自発話はほとんどない。復唱・系列語・あいさつの続きは言える。復唱、系列語、文の完成（1語を補う）、指さしカード
中等度質問に1〜3語で答えられる。語の列挙 3〜6語。質問に短文で答える、選択肢から文を作る、手順を話す

訓練の進め方と記録のしかた

3. 訓練の目標と優先順位

  • 目標：保たれている復唱を足場にして、「声を出し始める」経験を増やすこと。生活に必要な一言（要求・あいさつ・体調）を、手がかりがあれば言えるようにすること。
  • 優先順位：①復唱（単語→2語→短い文）で声を出す準備 → ②系列語・あいさつの続きで「自動的に出る言葉」を使う → ③文の完成（1語を補う、選択肢あり→絵あり→手がかりなし） → ④場面の一言と指さしカードで、実際に伝える。
  • 重度の段階では、正しく言えることより「言い始められること」を優先します。うまくいかない日は①②だけで終えて構いません。

4. ヒントの出し方（多い順に。成功したら一つずつ減らす）

  1. STと一緒に声を合わせて言う
  2. STのあとについて言う（復唱）
  3. 文の始まり＋答えの最初の音を言う（「雨が降ったので、か…」）
  4. 文の始まりだけを言う
  5. 選択肢や絵を見せる
  6. 手がかりなしで待つ（5〜10秒）

反応が出るまで5〜10秒は待ちます。待っても出ないときは、一つ多いヒントに戻ります。話し始めるまでの秒数と、どのヒントで言えたかを毎回記録します。

5. 家族への助言

  • 「何が食べたい？」より「ご飯とパン、どちらにしますか」のように、答えの言葉が含まれる質問にすると答えやすくなります。
  • 言葉が出るまで先回りせずに待ち、出なければ言い始めの一言（「お茶を…」）を添えます。
  • 復唱ができても、自分から言えるとは限りません。「まねはできるのに」と責めないよう伝えます。
  • 指さしカード（課題5）を食卓やベッドのそばに置き、言葉が出ないときに使ってもらいます。

6. 訪問での工夫

  • 毎回のあいさつ（「こんにちは」→「こんにちは」）や体調の確認を、最初の復唱練習として使います。
  • カレンダーの曜日、薬の袋、家族の写真など、家の中の物を系列語や文の完成の題材にします。
  • 疲れやすいので、1回の課題は10〜15分を目安にし、できた課題で終わるようにします。

7. 課題ページの一覧と記録のしかた

3：復唱課題（単語から短い文へ）／4：系列語課題（数・曜日・月・あいさつの続き）／5：文の完成課題 1（選択肢を見て1語を補う）／6：文の完成課題 2（絵を見て1語を補う）／7：伝達課題（場面の一言と指さしカード）／8：読み上げリスト・解答・評価のポイント。

各問の番号の左に段階（6 完全正答、5 遅延完全正答、4 不完全正答、3 ヒント後正答、2 関連反応、1 誤答）を記入し、6・5を正答とします。使ったヒントの番号（上の1〜6）も書き添えます。

内容は一般的な目安です。最終的な判断は担当の言語聴覚士が行ってください。

復唱課題

各行を「単語→2語→短い文」の順に、普通の速さで1回言います。言えなければもう一度ゆっくり言い、段階3とします。短い文まで言えた行は、STが「何がほしいですか」などと尋ね、文字を見ながら答えてもらいます（自発話への橋渡し）。

系列語課題

A〜Dは、STが最初の二つ（「1、2」）を言い、続きを待ちます。止まったら次の一つを言って再開し、言えたところまでを記録します。慣れたら、STは最初の一つだけにします。E の解答：1. ごちそうさまでした　2. 行ってらっしゃい　3. ございます　4. お願いします　5. おめでとうございます　6. さまでした　7. 失礼します　8. なっております（地域や家庭の言い方でも正答）。

文の完成課題 1（選択肢）

選択肢を読み上げるだけで終わったら、段階4とします。8割以上正答できたら、選択肢を紙で隠して同じ文で行います。

文の完成課題 2（絵）

1. 箸　2. 歯ブラシ　3. 帽子　4. 電話　5. 靴　6. 魚（「さんま」「鮭」なども正答）。出ないときは最初の音（「は…」）を与えて段階3とします。

伝達課題

A は、最初はSTが一言を先に言って復唱から始め、慣れたら場面だけを伝えて言えるかを見ます。B のカードは、家族にも使い方を説明します。実際の生活で使えたかどうか（家族から聞き取り）も記録します。

評価のポイント

①話し始めるまでの秒数　②使ったヒントの番号　③段階6・5の数、の三つを毎回書き、前回と比べます。復唱は良好なのに課題3〜5で手がかりが減らせない場合は、文の完成の段階に時間をかけます。選択肢を隠しても8割以上正答できる状態が続いたら、中等度の教材へ進みます。
