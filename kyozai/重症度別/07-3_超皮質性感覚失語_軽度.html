超皮質性感覚失語（軽度）の訓練教材

1. この段階の目安となるSLTAプロフィール

日常の会話や短い文はおおむね理解できるが、抽象的な語、たとえ（慣用句・比喩）、長い文章、複数の条件を含む指示で理解が崩れる段階です。音読は正確で話し方も流暢なため、周囲からは問題がないように見えやすく、書類の読み違いや指示の取り違えが生活上の困りごとになります。

領域正答率の目安特徴的な下位検査
聴く単語の理解 9割前後、短文の理解 8割前後、口頭命令に従う 7割前後長く複雑な命令で誤りが出る。
話す復唱・音読 10割／呼称 7〜8割、動作説明 7割、まんがの説明 段階3〜4、語の列挙 6〜9語意味性錯語がときどき残る。
読む単語の理解 9割、短文の理解 7割前後、書字命令に従う 7割前後音読は完全でも、文の理解に誤りが残る。
書く単語の書字 6〜8割、短文の書取 6割前後、まんがの説明（書字）段階3前後文章の組み立てに低下が残る。
計算7〜8割個人差が大きい。

重症度理解の目安教材の中心
重度単語の理解も2〜3割。反響言語が多い。具体物・線画との照合（2択）、はい／いいえの答え方の約束
中等度日常の単語は5〜7割理解。短文の理解は低い。意味の分類、説明に合う語、音読後の意味確認
軽度（この教材）日常会話はおおむね理解。抽象的な語・長い文で崩れる。抽象語・比喩・長文の理解、指示文書の読み取り

訓練の進め方と記録のしかた

3. 訓練の目標と優先順位

  • 目標：抽象的な語や慣用句を含む会話、新聞や手紙などの長い文章、病院・役所・家電などの指示文書を正しく読み取り、生活で困らないようにすること。
  • 優先順位：①抽象的な語の意味と反対の語 → ②慣用句・比喩の意味 → ③長い文章の事実・推論・要旨 → ④案内文の条件（日時・してはいけないこと）を読み取る → ⑤表や手順書から必要な情報を探す。
  • 「読めた」で終わらず、要点を自分の言葉で言い直すことを毎回の習慣にします。

4. ヒントの出し方（できるだけ減らす）

  1. 手がかりなしで答える
  2. 「文章のどこに書いてありますか」と、該当する段落を探してもらう
  3. 該当する文に線を引いて示す
  4. 文を短く区切って言い換えて示す

2で正答なら段階5、3〜4で正答なら段階3とします。誤りの種類（言葉の意味の取り違え／条件の読み落とし／推論の誤り）を分けて記録すると、次の練習の重点が分かります。

5. 家族への助言

  • 話し方が流暢なので理解も十分と思われがちですが、大事な書類や約束は、本人に要点を言い直してもらって確認します。
  • 冗談や遠回しな言い方、たとえは誤解されることがあります。伝わっていないときは、はっきりした言葉で言い直します。
  • 電話での約束は、メモに日時・場所を書いて残す習慣をつけます。

6. 訪問での工夫

  • 実際に届いた案内状・通知・薬の説明書・家電の取扱説明書を題材にします（個人情報の扱いに注意）。
  • 仕事への復帰を目指す方は、業務の手順書や社内の通知など、職場で読む文書を使います。
  • 時間を計って読み、速さと正確さの両方を記録します。

7. 課題ページの一覧と記録のしかた

3：理解課題 1（抽象的な語の意味）／4：理解課題 2（慣用句・たとえの意味）／5：読解課題 1（長い文章を読んで答える）／6：読解課題 2（案内文を読み取る）／7：読解課題 3（表と手順書を読み取る）／8：解答・評価のポイント。

各問の番号の左に段階（6 完全正答、5 遅延完全正答、4 不完全正答、3 ヒント後正答、2 関連反応、1 誤答）を記入し、6・5を正答とします。長文・案内文の課題は、読むのにかかった時間も書き添えます。

解答・評価のポイント

理解課題 1（抽象的な語）

正答のあとに、その語を使った短い文を一つ言ってもらうと、理解の確かさを確かめられます（例：「雨で運動会が延期になった」）。

理解課題 2（慣用句・たとえ）

字どおりの意味を選んだ誤りは段階2として記録します。正答後、どんな場面で使うかを話し合います。

読解課題 1（長い文章）

1. 妻（車で迎えに行った）　2. 三年ぶり　3. 荷物を持ってくれた　4. 卓球、来年は県の大会に出たい　5. イ（足が不自由で、坂道や長く歩くことが大変だから）　6. ウ（リハビリを続けて、一緒に散歩できるように頑張るという気持ち）。5・6は推論・要旨の問題で、本文に直接書かれていないことを読み取れるかを見ます。
