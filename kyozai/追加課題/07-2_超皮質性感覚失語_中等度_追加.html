超皮質性感覚失語（中等度） 追加課題集　ST用ガイド

1. この追加課題集のねらい

基本教材「超皮質性感覚失語（中等度）」の次に、または並行して使います。難しさは基本教材と同じ（3〜4択、2〜3語の指示、短い文）で、基本教材にない語と課題の形で練習量を増やします。聞いて分かる力を厚めにし、話す・読む・書くも組み合わせます。音読や復唱ができても意味が取れていないことがあるため、答えを選ぶ・動作で示す形で理解を確かめます。

2. 課題ページの一覧と難しさ

どの課題から始めるか：2・3ページから始め、正答が7割を超えたら4〜7ページへ、最後に8・9ページ（条件や順序を含む課題）へ進みます。

3. ヒントの出し方の順番

課題の種類ヒントの順番（①から順に。正答したらそこで止める）
呼称・喚語①意味・仲間（「果物の一つです」）→②使い道・場面（「皮をむいて食べます」）→③最初の音（「み…」）→④文字を見せる（「みかん」）→⑤一緒に言う（復唱）
理解①もう一度ゆっくり言う→②区切って言う→③指さし・身ぶりを添える→④文字を添える→⑤選択肢を減らす
書字①仮名で書いてもよい→②最初の1文字を見せる→③文字数の枠を示す→④見本を見て写す

4. 記録のしかた

各問の番号の左に段階（6 完全正答、5 遅延完全正答、4 不完全正答、3 ヒント後正答、2 関連反応、1 誤答）を記入し、6・5を正答とします。ヒントを使って正答した場合は段階4以下が目安です。ヒント欄のある課題は「ヒント（　）番目で正答」に番号を書き、前回と比べます。

音読の正誤と意味の正誤は分けて記録します。意味の近い語を選んだ誤りは段階2（関連反応）とし、何と取り違えたかを書きます。質問をオウム返しした問題には「反」と書き添えます。

5. ご家族向けの説明（このまま読み上げてください）

「ご本人は、言葉をはっきり言えたり、字をすらすら読めたりしますが、意味を取り違えることがあります。この課題では、聞いた言葉や読んだ言葉の意味を確かめる練習をします。問題は一度にゆっくり一つずつ読んでください。間違えても『違う』と言わず、もう一度ゆっくり言うか、選ぶものを減らしてください。名前の課題では、右側のヒントを上から順に一つずつ出してください。」

内容は一般的な目安です。最終的な判断は担当の言語聴覚士が行ってください。

聴理解課題 1（聞いた物を指さす）読み上げリスト

1.「財布を指さしてください」　2.「うちわを指さしてください」　3.「タオルとみかんを指さしてください」　4.「ろうそくとやかんを指さしてください」　5.「お湯をわかす物を指さしてください」　6.「食べられる物を指さしてください」　7.「財布を指さしてから、タオルを指さしてください」　8.「暑いときに使う物と、暗いときに使う物を指さしてください」。解答：1. イ　2. エ　3. ウ・オ　4. カ・ア　5. ア　6. オ　7. イ→ウ　8. エ・カ。2つの物は順序も正しくて正答とします。

呼称課題　解答

1. バケツ　2. フォーク　3. 靴下　4. ネクタイ　5. セーター　6. 机。③のあとは④文字を見せる→⑤一緒に言う。言えたあとに「何に使いますか」と尋ね、意味も結び付いたか確かめます。

読解課題 1（仲間でない語）解答

1. なす（果物）　2. 掃除機（楽器）　3. 大工（病院で働く人）　4. 朝（季節）　5. 船（道路を走る車）　6. 運動靴（季節の行事）　7. 財布（体の中の臓器）　8. ケーキ（麺類）。仲間の名前は似た言い方でも正答とします（例：「季節の行事」→「行事」「お祭り」）。

聴理解課題 2（はい・いいえ）読み上げリスト・解答

A：1.「夏は冬より暑いですか」はい　2.「魚は空を飛びますか」いいえ　3.「やかんでお湯をわかしますか」はい　4.「一週間は十日ですか」いいえ　5.「赤ちゃんはお年寄りより年上ですか」いいえ　6.「タオルで体をふきますか」はい。
B：7.「娘は午前中に病院へ行き、午後は家で休みました。」→「娘は午後に病院へ行きましたか」いいえ　8.「夫は散歩のあとで、シャワーを浴びました。」→「夫はシャワーを浴びてから散歩しましたか」いいえ　9.「隣の人から、みかんを箱でもらいました。」→「みかんをもらいましたか」はい　10.「明日は雨なので、庭の草取りは来週にします。」→「草取りは来週ですか」はい。

読解課題 2（文に合う語）解答

1. ア（セーター）　2. ウ（耳鼻科）　3. イ（明かり）　4. エ（流し）　5. ア（小包）　6. ウ（タオル）　7. イ（中止）　8. エ（銀行）

書字課題　解答例

A：1. みかん　2. ズボン　3. 手袋（てぶくろ）　4. 家（いえ）。B：乗り物＝電車・バス・自転車など、体の部分＝手・足・頭など、色＝赤・青・白など。書字のヒントは①仮名で書いてよい→②最初の1文字を見せる→③文字数の枠を指さす→④見本を見て写す。

聴理解課題 3（指示に従う）読み上げリスト

1.「丸を指さしてください」　2.「四角に×を付けてください」　3.「三角の下に線を引いてください」　4.「星と丸を指さしてください」　5.「みかんに○を付けてください」　6.「シャツを指さしてから、三角を指さしてください」　7.「お金を入れる物に線を引いてください」（財布）　8.「丸の中に、ご自分の名前の最初の一文字を書いてください」。指示を繰り返すだけで動けないときは「反」と書き、区切って言い直します。

読解課題 3（知らせ）解答

1. イ　2. ア　3. イ　4. ウ　5. ア　6. イ。読んだあとに、知らせの内容を家族に口で伝えてもらうと、理解の確認になります。
